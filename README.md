# Flogo

A prototype social-emotional learning (SEL) website for ages 15–25: four practice games (Crossroads, Read the Room, Reframe, Steady), four guided reset exercises, a daily mood check-in, and progress across the five CASEL skills.

Everything is a single static `index.html`. Progress is stored only in each visitor's browser; no data is collected.

Prototype only: scenario content has not yet had clinical review.
